  Shape 3 (Text 3, type=TEXT_BOX (17)):
Database Integration

  Shape 5 (Text 5, type=TEXT_BOX (17)):
MongoDB is used as the persistent data store
Default database configured by the server: query_performance_advisors
users collection stores email, hashed password and createdAt
reports collection stores title, SQL, analysis, userEmail and createdAt
Indexes: users.email unique; reports.createdAt; reports.userEmail + createdAt
Analysis history and dashboard statistics are queried per user account
MongoDB health status is checked through the /api/health endpoint
