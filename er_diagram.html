QueryPilot Data Architecture: 1-to-Many (1:N) User-to-Reports Relationship
Database: query_performance_advisors
User models/User.js
Key Field Type Constraint
PK _id ObjectId Unique, Auto-Gen
name String User display name
email String Unique Index, Lowercase
password String Hashed (bcryptjs)
createdAt Date Timestamp
1 : N (One-to-Many)
⟶
User._id = Report.userId
Report models/Report.js
Key Field Type Constraint
PK _id ObjectId Unique, Auto-Gen
FK userId ObjectId References User._id
query String Raw SQL / Execution Plan
databaseType String MySQL, Postgres, Mongo
executionTime / cost Number / Object Analysis metrics & score
recommendations Array / Text AI rewrites & indexes
createdAt Date Compound Index
Referential Integrity: JWT-bound session enforces user ownership of reports on every query.
Indexes: users.email (Unique)  |  reports.userId + createdAt (Compound)
